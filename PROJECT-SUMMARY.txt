🚀 HOW TO RUN

1️⃣  INSTALL DEPENDENCIES
    cd bmi-app
    npm install

2️⃣  START MONGODB (REQUIRED!)

    Windows:
      → MongoDB should auto-start as a service
      → If not: Open "Services" and start "MongoDB Server"
      → Or run: mongod

    macOS:
      brew services start mongodb-community

    Linux:
      sudo systemctl start mongod

3️⃣  START THE SERVER
    npm run dev          (development mode with auto-reload)
    OR
    npm start            (production mode)

4️⃣  OPEN BROWSER
    http://localhost:5000

🔌 API ENDPOINTS

PUBLIC (No token required):
  POST /api/auth/register    → Create account
  POST /api/auth/login       → Login

PROTECTED (Requires JWT token):
  POST /api/bmi              → Calculate & save BMI
  GET  /api/bmi              → Get all user's records
  DELETE /api/bmi/:id        → Delete single record
  DELETE /api/bmi            → Clear all records

🔧 TROUBLESHOOTING

❌ MongoDB connection error?
   → Install MongoDB: https://www.mongodb.com/try/download/community
   → Make sure it's running (see step 2 above)
   → Test connection: mongosh mongodb://127.0.0.1:27017/bmi_app

❌ Port 5000 already in use?
   → Edit .env and change PORT=5000 to PORT=3000 (or any free port)

❌ Module not found?
   → Run: npm install
